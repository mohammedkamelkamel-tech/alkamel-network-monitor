# مراقبة شبكة الكامل — Android

مشروع Android لمراقبة Access Points وأجهزة الشبكة عبر IP.

## المزايا الحالية
- إضافة نطاق IP مثل 10.0.0.2-10.0.0.100.
- إضافة IP يدويًا.
- اسم الجهاز، المكان، اسم الشخص، والملاحظات.
- فحص متوازٍ للأجهزة عبر TCP 80 ثم 443.
- عرض حالة متصل/غير متصل.
- تشغيل خدمة مراقبة خلفية.
- الأساس المطلوب لتأكيد الانقطاع بعد دقيقتين وتسجيل تاريخ الانقطاع والعودة.

> هذه النسخة هي نقطة البداية للمشروع. سيتم تطوير سجل الانقطاع والتنبيهات واختبارها على هاتف حقيقي قبل اعتمادها كنسخة إنتاجية.
